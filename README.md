# Poranna porcja

Prywatny, codzienny podcast (PL). Claude codziennie rano pisze scenariusz w `episodes/`, a GitHub Actions zamienia go na MP3 (głosy Microsoft Edge: Zofia i Marek) i publikuje w kanale RSS.

- Kanał podcastu: https://mstrejczek-prog.github.io/poranna-porcja/feed.xml
- Instrukcja dla Claude'a: `PROMPT.md`
- Generator audio i feedu: `scripts/build_episode.py`
- Ręczne przebudowanie: Actions -> "Zbuduj odcinek" -> Run workflow
